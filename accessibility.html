Accessibility Statement

Last updated: October 2026

St. John's Lodge No. 63, A.F. & A.M., Carleton Place, Ontario, a lodge under the Grand Lodge of A.F. & A.M. of Canada in the Province of Ontario, wants this public website to be readable and usable. That includes someone using a phone, a keyboard, or a screen reader.

How the pages are built

Pages use text, headings, and the same header and footer. A skip link goes to the main content. The contact form has labels. Meaningful images include alternative text. You can resize text in your browser and move through the links with a keyboard. The layout is meant to be readable on a small screen.

Other formats

If you need something on this site in another format, write to secretary@stjohns63.ca. Please name the page and the format that would help. The lodge will work with you to provide it.

What this statement does not claim

This is not a formal accessibility audit, and the lodge is not claiming a specific conformance level under the Accessibility for Ontarians with Disabilities Act or the Web Content Accessibility Guidelines. Some historical records are PDF files, which can be harder to read than the web pages. A secure members area is not available yet.

Fonts

The site uses Google Fonts (Cinzel and Inter), so the same typefaces can load on different computers.

Photo credits

Officer portraits used with each member's signed consent.

If you need help

If a page is hard to read or use, write to secretary@stjohns63.ca. Please name the page and what got in the way. Someone from the lodge will help.
